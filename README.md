### 🎮 pannek_ Game Launcher

Nowoczesny, lekki i w pełni spersonalizowany launcher gier stworzony z myślą o szybkim uruchamianiu rodzinnych produkcji webowych p5.js. Projekt oparty na języku Python z wykorzystaniem natywnej biblioteki graficznej Tkinter. 

### 🚀 Funkcje

* **Dark Mode:** Nowoczesny interfejs graficzny dopasowany do standardów aplikacji dla graczy.
* **Integracja z p5.js:** Bezpośrednie uruchamianie gier w domyślnej przeglądarce użytkownika bez pobierania zbędnych plików .exe.
* **Brak zależności:** Wykorzystuje wyłącznie wbudowane biblioteki Pythona (tkinter, webbrowser).

### 🕹️ Dostępne gry

1. **Geometry Clicker 🔺** – Szybka, zręcznościowa gra klikana.
2. **Bread Clicker 🍞** – Nowa produkcja w uniwersum chlebka.

*„Wybierz grę, albo chlebek albo dżem (ale się zrymowało)”* 

### 🛠️ Wymagania i instalacja

Aplikacja nie wymaga instalowania żadnych dodatkowych pakietów przez pip. Wystarczy posiadać zainstalowanego Pythona w wersji 3.x. 

1. Pobierz plik dywan.py.
2. Uruchom program za pomocą komendy: 

bash

python dywan.py

Używaj kodu z rozwagą.

*Ważne: Upewnij się, że ścieżka do folderu z projektem nie zawiera polskich znaków (takich jak ż, ś), aby uniknąć błędów systemowych konsoli PowerShell.*
